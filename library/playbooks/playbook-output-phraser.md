# Output phraser — STUB

**When the fellow runs it:** continuously, whenever agent output is going in front of a person.

**What it must contain, at minimum:**

1. Converting agent output into something a human can read and judge.
2. **A verification step, or an explicit handoff to the validator playbook.** This is the whole risk of
   this playbook: readable is not verified, and a phraser without a verification step ships
   comprehension and calls it verification.
3. The explanation register for a non-expert reader [D-29], which is a different genre from a
   fact-sheet and must not be merged into one artifact.

**Author's first decision:** whether item 2 lives here or in the validator playbook. It must live in
exactly one of them, and both stubs currently claim it.
