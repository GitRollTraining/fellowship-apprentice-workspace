# Judgment Cases — classification regression suite

Canonical hits for `references/classification.md`. Scripts are covered by `run-eval.sh`; THIS file covers the judgment rule. After any edit to classification.md, walk every case through the rule as written — each must reach its expected verdict from the quoted rule alone, without improvisation. A case that needs charity = a regression.

Scenario for all cases (unless a case states its own needle): renaming directory `area/old-name/` → `area/new-name/`.

Provenance: cases 1–11 were adjudicated adversarially against the rule during round 01 (pre-fix score: 3 clear-correct, 7 ambiguous, 1 wrong; the rule was rewritten as an explicit precedence lattice until every case resolved cleanly). Cases 12–13 encode the alias-scan and symlink-bypass false-positive classes.

**Cases 2 and 14 are a deliberate MINIMAL PAIR** — both are dated, UNFROZEN, body-prose citations, with opposite verdicts. If the lattice cannot separate them, the lattice is broken. **It failed to, three times running**, and each failure was a PRECEDENCE bug, not a wording bug:
1. Rule 2 froze case 14 on a manifest row's prose DESCRIPTION (a description is not a class).
2. Rule 7, as then written, blanket-froze every dated doc "regardless of where it lives".
3. Rule 3's body-prose clause — a VERDICT-PRODUCING clause sitting ABOVE rules 7-8 in a first-match-wins lattice — fired on unfrozen docs too and pre-empted them, making rule 8 dead code for any hit inside a prose sentence (i.e. most hits).
Rule 3 is now SCOPED to frozen containers only, which is the job it always claimed ("overrides rule 2 for the pointer line only"). Case 2 is decided by rule 8, not rule 3.
**In a first-match-wins lattice, a rule that produces a verdict as a side effect silently pre-empts every rule below it. Walk this pair FIRST after ANY classification.md edit, and check PRECEDENCE, not just wording.**

Cases 14–20 come from round 02's LIVE dogfood — every one is a real hit from a real workspace, not a crafted fixture. **14 and 15 are the important ones: both were verdicted WRONG on the first pass and caught by an adversarial audit.** Case 14 froze three live files on a manifest row's prose description while the workspace's own precedent had been fixing them; case 15 was decided with a rationale the rule did not actually license. In both, the RULE was the defect, not just the call — rule 2 gained the CLASS-field clause and rule 1 gained the DORMANT branch. Cases 17–19 are the self-hit shapes a correct fix necessarily creates.
